# Company recruitment

Jobs & careers is available on the customer home, dashboard and support screens. Anyone can read published vacancies; submitting requires a signed-in verified account and explicit consent. Admin → Customers & support (A22) → Manage jobs & applications is restricted to owner administrators.

Create a vacancy with location, employment type, description, requirements, application instructions and UTC deadline. Save as draft, publish or close it. Expired/closed positions cannot receive applications. Applicants submit their name, phone and experience/CV text. Attachments are not currently accepted. One application per account per vacancy; duplicate submissions return the existing reference.

Application statement, phone, name and the instructions accepted are encrypted using the existing application encryption key. Access remains owner-only. Latest 200 vacancies and 500 applications are shown. Reviews use optimistic versions. Status changes do not email applicants or automatically provision staff access. Arrange interviews/contact separately and issue worker accounts through the existing staff process.

Before collecting real applications, publish the organisation's recruitment privacy/retention policy and establish a process to fulfil applicant access/deletion requests. Recruitment records reside in the application database; protect backups and preserve the encryption key. The privacy policy draft must be updated and approved before public launch.

Deploy the backend and rebuild the mobile bundle to expose these controls in each platform. Existing installed APKs will not gain local interface changes until updated.
